# Contributing

Thanks for taking the time to contribute.

This project is still small, so I prefer focused changes that are easy to review and understand.

## Before opening a pull request

Please make sure your change:

- keeps the existing project structure
- uses clear and readable Luau
- does not introduce unnecessary dependencies
- includes a short explanation of what changed and why
- updates documentation if public behavior changes

## Bug reports

If you find a bug, please include:

- what you expected to happen
- what actually happened
- any relevant Roblox Studio output
- a small reproduction example if possible

## Pull requests

Keep pull requests focused on one improvement or fix when possible.

For larger changes, opening an issue first is usually better so the approach can be discussed before a lot of work is done.

## Style

This project uses StyLua formatting.

Try to keep naming clear and avoid adding complexity unless it solves a real problem.

## Security

Please do not publish API keys, tokens, private game data, or other sensitive information in issues or pull requests.
